Engineering project proposal

Toro Sushi Hand Roll Bar

Branded online ordering and internal admin portal — Seattle, WA

Client / Product
Toro Sushi Hand Roll Bar
Date
August 10, 2026
Status
Draft for review

01

Executive summary

Build a branded online ordering site and internal admin portal for Toro Sushi Hand Roll Bar: customers order and pay with Stripe; kitchen/staff manage orders and menu from a secure admin app.

Locked infrastructure

  • Next.js on Vultr VPS (~$5/mo) — hosts the web application and API
  • Supabase — Postgres database, Auth (admin login), and menu image storage
  • Stripe — checkout, refunds, and payment webhooks

02

Goals

  1. Customers can browse the menu, cart, pay online, and see order confirmation.
  2. Staff can log in, accept/progress orders, refund when needed, and manage the menu.
  3. Stack stays affordable for a single restaurant while remaining maintainable.
  4. Leave a clear path for dashboard/analytics; Phase 2.
  5. POS hardware integration until a vendor is chosen; Phase 2.

03

Stacks

  • App framework: Next.js on Vultr. Customer site, admin UI, API routes, and Stripe webhooks in one deployable app.
  • App hosting: Vultr VPS at ~$5/month. Fixed-cost Linux VM for the Next.js app, reverse proxy (Nginx), SSL, and Stripe webhook endpoint.
  • Database + Auth + file storage: Supabase. Managed Postgres for orders/menu/customers; Supabase Auth for staff roles; Supabase Storage for menu photos.
  • Payments: Stripe. Payment Element on checkout; server-side webhooks on the Vultr app for paid/failed/refunded events. Rules out Squarespace/WooCommerce checkout as the system of record.
  • Order type: pickup only. No delivery zones, delivery fees, or address validation in scope. Delivery is out of scope unless a future change order adds it.

04

Open decisions

POS integration

Vendor not chosen (Square / Toast / Clover / aggregator / none). Phase 2

05

Existing MVP site

https://juliusnugraha.github.io/toro-site

06

Scope by phase

Phase 1 — Launch

Time 3–4 weeks Cost $2,000
  • Deploy the Next.js website on our server.
  • Deploy the Supabase schema + Supabase Auth (staff) on our server.
  • Customer: guest checkout — menu from DB, cart → Stripe checkout → pickup order confirmation (no customer login)
  • Admin: login, Orders (status flow + refund), Menu CRUD + images + 86 toggle (out-of-stock item)
  • Stripe webhooks updating order payment status on our server.

Phase 2 — Operate

Time 3–4 weeks Cost $1,500
  • Dashboard KPIs
  • Analytics (revenue, top items, peak hours)
  • Customers list/detail (admin)
  • Customer login / accounts — sign up & sign in, order history, order status tracking, reorder
  • POS integration once vendor is chosen

Combined development (Phase 1 + Phase 2): $3,500 excluding POS vendor add-on, design/Figma, and monthly hosting
